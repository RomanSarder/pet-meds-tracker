---
name: fact-sweeper
description: >-
  Lists every unsourced specific in a document or summary — number, threshold,
  identifier, endpoint, field name, version, file path, date — so invented
  values can be caught before the text is read as authoritative. Run it on any
  output that will be cited later: a spec, a research summary, a plan, a
  migration note. Mechanical and cheap; it catches what the agent that wrote
  the text is structurally unable to see.
model: haiku
effort: medium
disallowedTools: [Edit, Write, NotebookEdit]
---
